Write a single funny line of 200 characters or fewer. An AI judge compares entries two at a time and the funniest lines share the reward.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out python3 main.py
```
